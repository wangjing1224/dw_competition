## 1. 目标

实现与具体模型供应方解耦的 Chat、Embedding 和 Rerank 适配层。首期使用阿里百炼的 OpenAI 兼容接口，业务代码只依赖内部接口，不直接使用百炼、Ollama、vLLM 等服务的私有响应字段。

## 3. 接口约定

- Chat：`base_url` 已包含 `/v1`，适配器追加 `/chat/completions`。
- Embedding：`base_url` 已包含 `/v1`，适配器追加 `/embeddings`。
- Rerank：内部统一接口，底层可调用本地 Python 或推理服务原生接口。
- 所有调用必须支持超时、有限重试和结构化错误。
- Chat 和 Embedding 使用 `langchain-openai` 封装；业务代码不直接导入或调用 OpenAI SDK。
- 第一版允许同一个 Qwen Chat 模型承担四类 LLM 调用，但 Prompt 和 Schema 独立。
- `configs/model.yaml` 按职责定义 `rule_extraction_model`、`evidence_classification_model`、`bid_chat_model`、`evidence_chat_model`、`embedding_model` 和 `rerank_model`。
- 每组配置都直接包含 `base_url`、`api_key`、`model` 和运行参数；URL、Key 使用 `${ENV_NAME}` 占位符，真实值来自 `.env`。
- 规则抽取、资料分类、主 Agent 和子 Agent 分别读取自己的完整模型配置，不在适配器或业务代码中硬编码模型名。
- 百炼切换为其他 OpenAI 兼容服务时，只替换 URL、Key 和模型名；不增加供应商分支类。

### 4.1 LangChain 模型工厂

```python
from langchain_openai import ChatOpenAI, OpenAIEmbeddings


def build_chat_model(settings) -> ChatOpenAI:
    return ChatOpenAI(
        model=settings.model,
        base_url=settings.base_url,
        api_key=settings.api_key,
        temperature=settings.temperature,
        max_completion_tokens=settings.max_output_tokens,
        timeout=settings.timeout_seconds,
        max_retries=settings.max_retries,
    )


def build_embedding_model(settings) -> EmbeddingModel:
    client = OpenAIEmbeddings(
        model=settings.model,
        base_url=settings.base_url,
        api_key=settings.api_key,
        dimensions=settings.dimension,
        chunk_size=settings.batch_size,
        request_timeout=settings.timeout_seconds,
        max_retries=settings.max_retries,
    )
    return EmbeddingModel(
        client=client,
        dimension=settings.dimension,
        batch_size=settings.batch_size,
    )
```

普通结构化调用仍执行本地 Pydantic 校验：

```python
async def invoke_structured(model, messages, output_type, mode):
    if mode in {"json_schema", "json_object"}:
        method = "json_schema" if mode == "json_schema" else "json_mode"
        structured = model.with_structured_output(
            output_type,
            method=method,
        )
        return await structured.ainvoke(messages)

    # prompt_only 用于兼容未完整实现 response_format 的服务。
    response: AIMessage = await model.ainvoke(
        append_schema_instruction(messages, TypeAdapter(output_type).json_schema())
    )
    return TypeAdapter(output_type).validate_python(
        extract_json_value(response.content)
    )
```

Agent 工具调用直接使用 LangChain 标准消息：

```python
model_with_tools = bid_chat_model.bind_tools(bid_agent_tools)
response: AIMessage = await model_with_tools.ainvoke(messages)
```

`AIMessage.tool_calls` 已是 LangChain 标准格式，可直接交给 LangGraph `ToolNode`。最终 Decision 没有 tool call 时，再使用 `BidAgentDecisionAdapter` 本地校验。

### 4.3 Embedding Adapter

```python
class EmbeddingModel:
    def __init__(self, client, dimension, batch_size):
        self.client = client
        self.dimension = dimension
        self.batch_size = batch_size

    async def embed(self, texts: list[str]) -> np.ndarray:
        if not texts:
            return empty_matrix(self.dimension)

        vectors = []
        for batch in batched(texts, self.batch_size):
            vectors.extend(await self.client.aembed_documents(batch))

        matrix = np.asarray(vectors, dtype=np.float32)
        validate_shape(matrix, rows=len(texts), cols=self.dimension)
        return l2_normalize(matrix)
```

### 4.4 Rerank Adapter

```python
class RerankModel:
    async def rerank(self, query, documents, top_n):
        if not documents:
            return []

        raw_scores = await retry_with_policy(
            lambda: self.backend.score(query, documents),
            max_retries=self.max_retries,
        )
        ranked = sorted(
            zip(documents, raw_scores),
            key=lambda item: item[1],
            reverse=True,
        )
        return [
            RerankResult(
                document_id=doc.document_id,
                score=score,
            )
            for doc, score in ranked[:top_n]
        ]
```

Rerank 输入必须携带稳定 `document_id`，不能只传字符串后再按内容反查来源。

### 4.5 错误分类

```python
try:
    return await model_call()
except TimeoutError:
    raise ModelCallError(code="model_timeout", retryable=True)
except InvalidSchemaResponse:
    raise ModelCallError(code="invalid_structured_output", retryable=True)
except AuthenticationError:
    raise ModelCallError(code="model_auth_failed", retryable=False)
```

## 5. 结构化输出策略

`structured_output_mode` 由配置选择，不假设所有 OpenAI 兼容服务都实现同一种 `response_format`。优先级：

1. 服务原生 JSON Schema/structured output。
2. 服务仅支持 JSON object 时，在 Prompt 中附 Schema，并在本地严格校验。
3. 首次校验失败后允许一次“仅修复格式”的重试。
4. 再次失败则返回结构化错误，不把未校验字典交给业务层。

## 6. 测试设计

- 使用 Mock Server 验证 URL、超时、Header 和请求体。
- 验证 API Key 通过 Bearer Header 发送，且不会出现在日志中。
- 验证六组模型配置中的 URL/Key 占位符均能从环境变量解析。
- 验证四类 Chat 调用分别使用自己的模型名、温度、超时和结构化输出模式。
- 修改 YAML 中的模型名后，业务代码和适配器代码无需修改。
- `ChatOpenAI.bind_tools()` 返回标准 `AIMessage.tool_calls`，可被 ToolNode 执行。
- 普通 JSON、Markdown JSON 均能执行本地 Pydantic 校验。
- 使用百炼兼容地址时不会重复拼接 `/v1/v1`。
- `BidAgentDecision` 等判别联合可通过 `TypeAdapter` 校验和导出 Schema。
- 缺字段、额外字段和错误枚举值不能通过结构化输出校验。
- Embedding 返回顺序与输入顺序一致。
- 维度错误立即失败，不能写入索引。
- Rerank 不可用时按配置选择“降级为初召回排序”或“返回错误”，不得静默伪造分数。

## 7. Embedding 变更与索引重建

Embedding 模型名、服务地址、输出维度或其他影响向量语义的配置发生变化后，旧向量索引不得继续复用。

当前比赛开发阶段不增加单独的“重建索引”接口，使用最简单的全量重建流程：

```text
1. 停止后端服务。
2. 删除 data/indexes/ 和 data/app.db。
3. 重新启动服务，由应用创建新的 SQLite 数据库。
4. 重新调用 POST /api/projects，重建 RuleSet 和 Rule Source Index。
5. 重新调用 POST /api/projects/{project_id}/bidders，重建 Evidence Index。
6. 重新创建 AuditTask；任务执行时自动构建新的 Bid Document Index。
```

该流程会清空当前本地演示数据。进入需要保留项目和投标方元数据的阶段后，再增加内部重建命令或管理接口；当前任务不提前实现。

## 8. 验收标准

- 业务层没有直接导入 Ollama 客户端或 OpenAI SDK。
- Chat、Embedding、Rerank 均可通过配置替换后端。
- 每类模型的 URL、Key、模型名、温度、最大输出 token、超时和重试次数均可独立配置。
- 模型私有字段、思考内容和结构化输出差异在适配层处理。
- 所有调用有超时、有限重试、日志和结构化错误。
