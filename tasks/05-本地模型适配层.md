# 任务 05：本地模型适配层

## 1. 目标

实现与具体推理框架解耦的 Chat、Embedding 和 Rerank 适配层。业务代码只依赖内部接口，不直接使用 Ollama、vLLM 或其他服务的私有响应字段。

## 2. 建议文件

```text
app/llm/
├── chat_model.py
├── embedding_model.py
├── rerank_model.py
├── structured_output.py
└── errors.py
```

## 3. 接口约定

- Chat：OpenAI 兼容 `/v1/chat/completions`。
- Embedding：OpenAI 兼容 `/v1/embeddings`。
- Rerank：内部统一接口，底层可调用本地 Python 或推理服务原生接口。
- 所有调用必须支持超时、有限重试和结构化错误。
- 第一版允许同一个 Qwen 9B 模型承担四类 LLM 调用，但 Prompt 和 Schema 独立。

## 4. 核心伪代码

### 4.1 Chat Adapter

```python
class ChatModel:
    def __init__(self, settings, http_client):
        self.base_url = settings.base_url
        self.model = settings.model
        self.timeout = settings.timeout
        self.client = http_client

    async def complete_structured(
        self,
        messages: list[Message],
        output_model: type[BaseModel],
        tools: list[ToolSpec] | None = None,
    ) -> BaseModel:
        schema = output_model.model_json_schema()
        payload = {
            "model": self.model,
            "messages": normalize_messages(messages),
            "tools": normalize_tools(tools),
            "response_format": build_response_format(schema),
            "temperature": 0,
        }

        raw = await retry_with_policy(
            lambda: self.client.post(
                f"{self.base_url}/v1/chat/completions",
                json=payload,
                timeout=self.timeout,
            )
        )
        content = normalize_chat_response(raw)

        # 私有 thinking 字段或 Markdown 包裹在适配层清理。
        json_value = extract_json_value(content)
        return output_model.model_validate(json_value)
```

### 4.3 Embedding Adapter

```python
class EmbeddingModel:
    async def embed(self, texts: list[str]) -> np.ndarray:
        if not texts:
            return empty_matrix(self.dimension)

        vectors = []
        for batch in batched(texts, self.batch_size):
            response = await post_embeddings(batch)
            ordered = sort_by_response_index(response.data)
            vectors.extend(item.embedding for item in ordered)

        matrix = np.asarray(vectors, dtype=np.float32)
        validate_shape(matrix, rows=len(texts), cols=self.dimension)
        return l2_normalize(matrix)
```

### 4.4 Rerank Adapter

```python
class RerankModel:
    async def rerank(self, query, documents, top_n):
        if not documents:
            return []

        raw_scores = await self.backend.score(query, documents)
        ranked = sorted(
            zip(documents, raw_scores),
            key=lambda item: item[1],
            reverse=True,
        )
        return [
            RerankResult(document=doc, score=score)
            for doc, score in ranked[:top_n]
        ]
```

try:
    return await model_call()

## 5. 结构化输出策略

优先级：

1. 服务原生 JSON Schema/structured output。
2. 服务仅支持 JSON object 时，在 Prompt 中附 Schema，并在本地严格校验。
3. 首次校验失败后允许一次“仅修复格式”的重试。
4. 再次失败则返回结构化错误，不把未校验字典交给业务层。

## 6. 测试设计

- 使用 Mock Server 验证 URL、超时、Header 和请求体。
- 服务返回 tool calls、普通 JSON、Markdown JSON 时均能归一化。
- 缺字段、额外字段和错误枚举值不能通过结构化输出校验。
- Embedding 返回顺序与输入顺序一致。
- 维度错误立即失败，不能写入索引。
- Rerank 不可用时按配置选择“降级为初召回排序”或“返回错误”，不得静默伪造分数。

## 7. 验收标准

- 业务层没有直接导入 Ollama 客户端。
- Chat、Embedding、Rerank 均可通过配置替换后端。
- 模型私有字段、思考内容和结构化输出差异在适配层处理。
- 所有调用有超时、有限重试、日志和结构化错误。

## 8. 非目标

- 不在本任务实现 Prompt 内容。
- 不实现 Agent 循环。
- 不把素材库的全局模型单例直接迁入主工程。
