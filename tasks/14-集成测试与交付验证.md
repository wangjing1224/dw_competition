def test_competition_dataset_end_to_end(api_client, dataset):
    project = api_client.create_project(
        folder=dataset.tender_bundle,

    bidder = api_client.create_bidder(
        project_id=project.project_id,

    task = api_client.create_audit_task(
        project_id=project.project_id,
        bidder_id=bidder.bidder_id,
        folder=dataset.bid_test_set,
    )

    completed = wait_until_terminal(task.task_id)
    assert completed.status in {
        "completed",
        "completed_with_report_error",
    }

    result = AuditResult.model_validate(completed.result)
    assert len(result.file_results) == 3

    assert file_result("招标采购测试集.docx").is_applicable is True
    assert file_result("物资类公开招标采购.docx").is_applicable is True

## 5. 比赛数据验收点

### 5.1 规则解析

- 生成结构化 RuleSet。
- 每条规则有来源。
- 能识别包级需求。
- 能处理参数冲突。

### 5.2 投标审核

- 两份红外热成像仪文件进入审核。
- 机械加工设备文件排除。
- 发现报价空缺、授权信息空缺、参数冲突等问题。
- 每条适用规则都有结果。

### 5.3 资料核验

- 能检索合同、业绩、技术参数、资质和售后资料。
- 能区分支持、部分支持、缺失、冲突、OCR 和不可验证。
- 异类文件不触发资料核验。

### 5.4 输出

- 生成一份任务级 JSON。
- JSON 包含三个文件的独立结果。
- 适用文件生成 Word。
- 所有结论可追溯。
