# 任务 11：资料核验子智能体

## 1. 目标

实现 `evidence_subagent` ReAct 循环和 `request_evidence_review` Tool。每次调用只核验一条 Claim，返回严格结构化的 `EvidenceReviewResult`。

## 3. 输入输出边界

输入：

```text
Claim + task_id + project_id + bidder_id
```

内部可调用：

- `search_evidence`
- `retrieve_evidence_source`

输出：

```text
EvidenceReviewResult
```

不得返回子 Agent 完整消息历史，不得修改 RuleSet、AuditState 或最终报告。

## 4. EvidenceState

```python
class EvidenceState(TypedDict):
    messages: Annotated[list[BaseMessage], add_messages]
    task_id: str
    project_id: str
    bidder_id: str
    claim: Claim
    review_result: EvidenceReviewResult | None
    errors: list[TaskError]
    step_count: int
```

## 5. 核心伪代码

### 5.1 子图构建

```python
def build_evidence_graph():
    graph = StateGraph(EvidenceState)
    evidence_tools = [
        SearchEvidenceTool(retrieval_service=retrieval_service),
        RetrieveEvidenceSourceTool(source_store=source_store),
    ]
    agent_node = partial(
        evidence_agent_node,
        tools=evidence_tools,
    )

    graph.add_node("agent", agent_node)
    graph.add_node("tools", ToolNode(evidence_tools))
    graph.add_node("finalize", finalize_evidence_review)

    graph.set_entry_point("agent")
    graph.add_conditional_edges(
        "agent",
        route_evidence_agent,
        {
            "tools": "tools",
            "finalize": "finalize",
            "limit_reached": "finalize",
        },
    )
    graph.add_edge("tools", "agent")
    graph.add_edge("finalize", END)
    return graph.compile()
```

### 5.2 Agent 节点

```python
async def evidence_agent_node(state, tools: list[BaseTool]):
    messages = build_evidence_messages(
        system_prompt=load_prompt("evidence_subagent"),
        claim=state.claim,
        react_messages=state.messages,
        errors=state.errors,
    )

    model_with_tools = evidence_chat_model.bind_tools(tools)
    response: AIMessage = await model_with_tools.ainvoke(messages)

    return {
        "messages": [response],
        "step_count": state.step_count + 1,
    }
```

### 5.3 路由

```python
def route_evidence_agent(state):
    last = state.messages[-1]

    if last.tool_calls:
        if state.step_count >= settings.evidence_max_steps:
            return "limit_reached"
        return "tools"
    if can_parse_review_result(last.content):
        return "finalize"
    if state.step_count >= settings.evidence_max_steps:
        return "limit_reached"
    return "agent"
```

`build_evidence_messages` 返回：

```text
SystemMessage
  + 当前 Claim 的 HumanMessage
  + state.messages 中完整的 AIMessage / ToolMessage 历史
```

不得只传 ToolMessage；工具结果必须与发起调用的 AIMessage 成对保留。

### 5.4 结果收口

```python
def finalize_evidence_review(state):
    if final_message_contains_valid_result(state):
        result = parse_evidence_review_result(state.messages[-1])
    else:
        # 工具失败、步数超限或输出无法校验时，形成可继续主任务的结果。
        result = EvidenceReviewResult(
            evidence_result_id=generate_id("evidence-result"),
            claim_id=state.claim.claim_id,
            task_id=state.task_id,
            project_id=state.project_id,
            bidder_id=state.bidder_id,
            bid_file_id=state.claim.bid_file_id,
            rule_id=state.claim.rule_id,
            status="unverifiable",
            evidence_found=source_refs_from_tool_messages(state.messages),
            missing_evidence=[],
            consistency_issues=[],
            manual_review_reason=describe_errors(state.errors),
            summary="自动资料核验未能形成可靠结论，需人工复核",
        )

    validate_result_matches_claim(result, state.claim)
    return {"review_result": result}
```

### 5.5 主 Agent 可调用 Tool

以下类写在 `app/tools/bid_tools.py`，因为它属于 `bid_agent` 的工具集合：

```python
class RequestEvidenceReviewInput(BaseModel):
    model_config = ConfigDict(extra="forbid")

    claim: Claim


class RequestEvidenceReviewTool(BaseTool):
    name: str = "request_evidence_review"
    description: str = load_tool_description("request_evidence_review")
    args_schema: ClassVar[type[BaseModel]] = RequestEvidenceReviewInput

    evidence_graph: CompiledStateGraph

    async def _arun(self, claim: Claim) -> dict:
        # Claim 由主 Agent 产生，子 Agent 直接信任该内部契约。
        final_state = await self.evidence_graph.ainvoke(
            build_initial_evidence_state(claim)
        )
        return require_review_result(final_state).model_dump(mode="json")

    def _run(self, **kwargs):
        raise ToolException("request_evidence_review 仅支持异步调用")
```

## 6. 判断要求

子智能体必须区分：

- `supported`
- `partially_supported`
- `unsupported`
- `contradicted`
- `ocr_required`
- `unverifiable`
- `weakly_related`

仅凭文件名或候选摘要不能输出 `supported`；至少需要回查相关原文或表格。

## 7. Prompt 约束

- 固定 Prompt 正文保存在 `configs/prompts/templates/evidence_subagent.md`。
- Claim、候选证据、原文和错误由 `app/agents/evidence_subagent.py` 组装为运行时消息。
- 只判断当前 Claim。
- 优先按 `required_evidence_types` 检索。
- 材料存在不等于材料支持声明。
- 主体、产品、型号、数量、日期等冲突进入 `consistency_issues`。
- 图片不可读、脱敏和外部平台真实性核验分别使用明确状态。
- 最终输出严格符合 `EvidenceReviewResult`。

## 8. 测试设计

- 完整合同和发票链返回 `supported`。
- 有合同但缺发票查验材料返回 `partially_supported`。
- 未找到材料返回 `unsupported`。
- 材料型号与 Claim 冲突返回 `contradicted`。
- 图片型证书返回 `ocr_required`。
- 脱敏或需外部平台验证返回 `unverifiable`。
- 子 Agent 不能访问其他 bidder 的资料。
- 工具超时或步数超限时返回可追踪的人工复核结果。

## 9. 验收标准

- 每次调用只有一个 Claim 和独立 EvidenceState。
- `RequestEvidenceReviewTool` 继承 BaseTool，并通过构造函数注入已编译子图。
- 子 Agent 消息不写回 AuditState。
- 检索候选和原文以 ToolMessage 作为单一运行时来源，不维护重复 State 列表。
- 返回结果 ID 和归属与 Claim 完全一致。
- 结果包含证据来源、缺失项、冲突项和摘要。
