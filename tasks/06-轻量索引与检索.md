# 任务 06：轻量索引与检索

## 1. 目标

实现本地文本分段、向量矩阵存储、关键词召回、余弦相似度召回、元数据过滤和 Rerank，为规则来源、投标文件和投标方资料提供统一检索能力。

## 3. 索引边界

本任务开始前增加本地矩阵依赖：

```bash
uv add numpy
```

每个片段必须包含：

- `chunk_id`
- `file_id`
- `project_id`
- `bidder_id`
- `task_id`
- `data_role`
- `source_path`
- `section`
- `content`
- `parse_status`
- 可选 `evidence_type`

检索必须先按元数据过滤，再计算相似度。不得使用素材库中的全局 Elasticsearch 索引。

## 4. 存储建议

每个逻辑索引目录保存：

```text
index.json             # 版本、维度、条目数、构建状态
chunks.jsonl           # 片段正文和元数据
embeddings.npy         # 与 chunks 顺序严格一致的 float32 矩阵
keyword_index.json     # 轻量倒排信息
```

`index.json` 还必须记录 Embedding 模型名和配置指纹。加载索引时若当前模型指纹不一致，即使向量维度相同也拒绝复用旧索引并要求重建。

索引构建使用临时目录，全部成功后原子替换，避免任务中断留下半成品。

## 5. 核心伪代码

### 5.1 文本分段

```python
def chunk_parsed_document(parsed: ParsedDocument) -> list[IndexChunk]:
    chunks = []

    for section in parsed.sections:
        units = [section.content, *section.tables]
        for unit in units:
            for text in split_with_overlap(
                unit,
                max_tokens=settings.chunk_tokens,
                overlap_tokens=settings.chunk_overlap,
            ):
                if not text.strip():
                    continue

                chunks.append(
                    IndexChunk(
                        chunk_id=generate_id("chunk"),
                        file_id=parsed.document.file_id,
                        section=section.title,
                        content=text,
                        # 继承完整业务归属，检索时不得补猜。
                        **parsed.document.owner_metadata,
                    )
                )
    return chunks
```

### 5.2 构建索引

```python
async def build_document_index(index_scope, documents):
    all_chunks = []
    for document in documents:
        parsed = load_parsed_document(document.file_id)
        all_chunks.extend(chunk_parsed_document(parsed))

    texts = [
        f"{chunk.section}\n{chunk.content}"
        for chunk in all_chunks
    ]
    vectors = await embedding_model.embed(texts)
    keyword_index = build_keyword_index(all_chunks)

    with atomic_index_directory(index_scope) as temp_dir:
        write_chunks(temp_dir, all_chunks)
        np.save(temp_dir / "embeddings.npy", vectors)
        write_keyword_index(temp_dir, keyword_index)
        write_manifest(
            temp_dir,
            status="ready",
            dimension=vectors.shape[1],
            chunk_count=len(all_chunks),
            embedding_model=embedding_settings.model,
            embedding_fingerprint=embedding_config_fingerprint(
                embedding_settings
            ),
        )
```

### 5.3 强制元数据过滤

```python
def filter_chunks(chunks, query_filter):
    required = required_identity_fields(query_filter.data_role)
    ensure_present(query_filter, required)

    return [
        chunk
        for chunk in chunks
        if chunk.project_id == query_filter.project_id
        and optional_equal(chunk.bidder_id, query_filter.bidder_id)
        and optional_equal(chunk.task_id, query_filter.task_id)
        and chunk.data_role == query_filter.data_role
        and optional_in(chunk.evidence_type, query_filter.evidence_types)
    ]
```

### 5.4 混合召回和 Rerank

```python
async def search(query, query_filter, candidate_top_k, final_top_k):
    index = load_index(query_filter.scope)
    candidate_rows = filter_chunks(index.chunks, query_filter)

    if not candidate_rows:
        return []

    query_vector = (await embedding_model.embed([query]))[0]
    semantic = cosine_top_k(
        query_vector,
        index.vectors_for(candidate_rows),
        k=candidate_top_k,
    )
    keyword = keyword_top_k(
        query,
        candidate_rows,
        k=candidate_top_k,
    )

    # 以 chunk_id 去重并保留两类召回分数。
    merged = merge_recall_results(semantic, keyword)
    reranked = await rerank_model.rerank(
        query=query,
        documents=[
            RerankDocument(
                document_id=item.chunk.chunk_id,
                text=item.chunk.content,
            )
            for item in merged
        ],
        top_n=final_top_k,
    )
    return attach_source_refs_by_chunk_id(reranked, merged)
```

### 5.5 精确编号保护

```python
def keyword_tokens(text):
    # 型号、包号、标准号、日期和数值不能仅依赖中文分词。
    exact = extract_patterns(
        text,
        patterns=[MODEL_NO, PACKAGE_NO, STANDARD_NO, DATE, NUMBER_UNIT],
    )
    words = chinese_tokenize(text)
    return deduplicate([*exact, *words])
```

## 7. 测试设计

- 相同文本在不同 bidder 下只能检索到当前 bidder 的结果。
- 投标文件检索必须携带 task_id。
- 规则来源检索必须携带 project_id。
- 型号、包号、标准号和数值可通过关键词召回。
- 向量矩阵行数与 chunk 数不一致时索引拒绝加载。
- Embedding 模型或关键配置变化后旧索引拒绝加载并要求重建。
- 索引构建中断时旧索引仍可用。
- Rerank 后结果保留原始 SourceRef。
- 内容完全相同的两个 chunk 经 Rerank 后仍能按 chunk_id 正确回链。

## 8. 当前重建策略

Embedding 配置指纹变化时，索引加载应明确返回“需要重建”，不得自动混用旧向量。当前开发阶段通过删除 `data/indexes/` 和 `data/app.db`，再重新调用项目上传、投标方资料上传和审核任务接口完成全量重建；不新增独立重建 API。

## 9. 验收标准

- 三类索引共用统一接口，但数据范围严格隔离。
- 当前数据量下无需外部向量数据库即可完成检索。
- 检索结果包含片段、分数和可回查来源。
- 可独立运行检索测试，不依赖 Agent。
