# 任务 04：文档解析与统一解析结果

## 1. 目标

实现 DOCX、XLSX、TXT/Markdown 的统一解析接口，保留章节、表格、图片状态和来源信息，并将素材库中的可用解析逻辑适配到当前领域模型。

## 2. 建议文件

```text
app/parsers/
├── base.py
├── models.py
├── registry.py
├── docx_parser.py
├── xlsx_parser.py
├── text_parser.py
└── doc_converter.py
```

## 3. 素材复用方案

从 `material/lib-zlf` 参考或提取：

- DOCX 段落与表格读取。
- 表格转 Markdown 的逻辑。
- 文本编码识别。
- 基础 token/分隔符切分。

必须补齐：

- 标题层级和章节路径。
- 表格与正文的原始顺序。
- `file_id`、`source_path` 和 `section_id`。
- 图片数量和 OCR 状态。
- 统一异常到 `ParseStatus`。

素材当前 `ParsedChunk` 仅包含 `content/source`，不足以直接作为系统解析结果。

## 5. 核心伪代码

### 5.1 统一解析入口

```python
def parse_document(document: DocumentRef) -> ParsedDocument:
    stored_path = file_store.resolve(document.file_id)
    parser = parser_registry.get(stored_path.suffix.lower())

    if parser is None:
        return ParsedDocument(
            document=document,
            parse_status="unsupported",
            sections=[],
            warnings=["当前格式无可用解析器"],
        )

    try:
        result = parser.parse(document, stored_path)
        update_file_parse_status(document.file_id, result.parse_status)
        write_parsed_result_atomic(document.file_id, result)
        return result
    except RecoverableParseError as exc:
        # 文件仍有部分文本时保留部分结果。
        result = exc.partial_result.with_status("partial")
        persist(result)
        return result
    except Exception as exc:
        update_file_parse_status(document.file_id, "manual_review")
        record_parse_error(document.file_id, exc)
        return failed_parse_result(document, exc)
```

### 5.2 DOCX 顺序解析

```python
def parse_docx(document, path):
    doc = python_docx_open(path)
    heading_stack = []
    sections = []
    current = new_section(title="文档开始")
    image_count = 0

    # 必须遍历 body 子节点，保持段落和表格原始顺序。
    for block in iter_docx_blocks_in_order(doc):
        if block.is_paragraph:
            if is_heading(block):
                flush_non_empty(current, sections)
                heading_stack = update_heading_stack(
                    heading_stack,
                    level=heading_level(block),
                    title=block.text,
                )
                current = new_section(
                    title=" > ".join(heading_stack),
                    source_block_index=block.index,
                )
            else:
                current.content_parts.append(clean_text(block.text))
                image_count += count_images(block)

        elif block.is_table:
            table = convert_table_to_markdown(block)
            current.tables.append(table)

    flush_non_empty(current, sections)

    status = derive_parse_status(
        has_text=any_text(sections),
        image_count=image_count,
        unreadable_objects=count_unreadable_objects(doc),
    )
    return ParsedDocument(..., sections=sections, parse_status=status)
```

### 5.3 XLSX 解析

```python
def parse_xlsx(document, path):
    workbook = openpyxl.load_workbook(path, data_only=True, read_only=True)
    sections = []

    for sheet in workbook.worksheets:
        rows = normalize_merged_cells_and_values(sheet)
        markdown = rows_to_markdown(rows)
        sections.append(
            ParsedSection(
                section_id=generate_id("section"),
                title=f"Sheet: {sheet.title}",
                content="",
                tables=[markdown],
                image_count=count_sheet_images(sheet),
            )
        )
    return ParsedDocument(..., sections=sections)
```

## 6. 解析状态判定

- `parsed`：正文和表格足以用于检索。
- `partial`：部分对象无法读取，但仍有可用文本。
- `ocr_required`：主要内容由图片构成，文本不足。
- `unsupported`：格式或转换能力不可用。
- `manual_review`：解析异常或内容不足，无法可靠自动处理。

## 7. 测试设计

- DOCX 中段落和表格顺序不被打乱。
- 标题层级能形成稳定章节路径。
- 合并单元格、空单元格和多行表头可读。
- 图片型文档能标记 `ocr_required`，不根据文件名猜测内容。
- UTF-8、GBK 等 TXT 可读取；无法识别编码时进入人工复核。
- XLSX 每个 Sheet 都有独立来源位置。
- 同一文档重复解析结果稳定。

## 8. 验收标准

- 支持设计要求的 DOCX、XLSX、TXT/Markdown。
- 每个解析结果保留 `file_id`、文件来源和章节定位。
- 表格进入统一解析结果，可供后续分段和原文回查。
- 素材解析能力已被适配，不携带 Elasticsearch 或直接模型依赖。
