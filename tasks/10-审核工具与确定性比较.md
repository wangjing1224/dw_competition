### 4.1 投标响应检索

```python
@tool
async def search_bid_response(
    task_id: str,
    bid_file_id: str,
    rule: RuleItem,
) -> BidResponseSearchResult:
    task = require_task(task_id)
    require_file_belongs_to_task(bid_file_id, task_id)

    query = build_rule_query(rule)
    hits = await retrieval.search(
        query=query,
        query_filter=IndexFilter(
            project_id=task.project_id,
            bidder_id=task.bidder_id,
            task_id=task.task_id,
            data_role="bid_document",
            file_ids=[bid_file_id],
        ),
    )

    extracted_values = extract_comparable_values(hits, rule.target_field)
    comparison = compare_if_possible(rule, extracted_values)
    return BidResponseSearchResult(
        candidates=hits,
        extracted_values=extracted_values,
        comparison=comparison,
    )
```

### 4.3 证据检索

```python
@tool
async def search_evidence(claim: Claim) -> list[EvidenceCandidate]:
    # 不接受调用方覆盖 project_id/bidder_id，直接使用 Claim 归属。
    hits = await retrieval.search(
        query=claim.statement,
        query_filter=IndexFilter(
            project_id=claim.project_id,
            bidder_id=claim.bidder_id,
            task_id=None,
            data_role="evidence_material",
            evidence_types=claim.required_evidence_types,
        ),
    )
    return [to_evidence_candidate(hit) for hit in hits]
```

### 4.5 确定性比较

```python
def compare_values(operator, expected, actual, value_type, unit=None):
    if actual is None or actual == "":
        return ComparisonResult(status="missing")

    normalized_expected = normalize_value(expected, value_type, unit)
    normalized_actual = normalize_value(actual, value_type, unit)

    match operator:
        case ">=":
            matched = normalized_actual >= normalized_expected
        case "<=":
            matched = normalized_actual <= normalized_expected
        case "equals":
            matched = normalized_actual == normalized_expected
        case "contains_all":
            matched = set(normalized_expected) <= set(normalized_actual)
        case "date_before":
            matched = normalized_actual <= normalized_expected
        case _:
            return ComparisonResult(status="unsupported_operator")

    return ComparisonResult(
        status="matched" if matched else "not_matched",
        raw_expected=expected,
        raw_actual=actual,
        normalized_expected=normalized_expected,
        normalized_actual=normalized_actual,
    )
```

## 5. 工具返回约束

- 返回结构化模型，不返回自由文本大段拼接。
- 候选结果必须包含分数和 SourceRef。
- 工具不能直接修改 AuditState。
- 工具不能改变 RuleSet。
- 工具不能根据文件名直接下证据结论。
- 所有身份参数在服务端二次校验。

## 6. 错误处理

```python
try:
    return await search(...)
except TimeoutError:
    return ToolFailure(
        error=TaskError(
            code="tool_timeout",
            stage="bid_search",
            retryable=True,
            ...
        )
    )
```

工具失败应可被 Agent 转换为 `manual_review`，只有上下文损坏等不可恢复错误才终止任务。

## 7. 测试设计

- 传入其他 task 的 file_id 必须被拒绝。
- 传入其他 bidder 的 candidate 必须被拒绝。
- `search_evidence` 强制使用 Claim 的证据类型。
- 数值、日期、空字段、枚举、列表、型号和包号比较有独立测试。
- 单位转换无法确认时返回 `manual/unsupported`，不猜测。
- 原文回查返回解析状态和精确来源。

## 8. 验收标准

- 五个工具具有明确输入输出 Schema。
- 确定性比较不注册为 LLM Tool。
- 工具结果足以支持主/子 Agent 判断和报告溯源。
- 数据隔离测试全部通过。
