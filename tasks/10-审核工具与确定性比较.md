## 4. 核心伪代码

### 4.1 BaseTool 与输入 Schema 约定

```python
from typing import ClassVar

from langchain_core.tools import BaseTool
from pydantic import BaseModel, ConfigDict, Field


class SearchBidResponseInput(BaseModel):
    model_config = ConfigDict(extra="forbid")

    task_id: str = Field(description="当前审核任务 ID")
    bid_file_id: str = Field(description="当前投标文件 ID")
    rule: RuleItem = Field(description="当前待审核规则")


class SearchEvidenceInput(BaseModel):
    model_config = ConfigDict(extra="forbid")

    claim: Claim = Field(description="主 Agent 生成的单条待核验声明")
```

约束：

- 每个工具都是独立的 `BaseTool` 子类，不使用 `@tool` 装饰器。
- `name` 使用设计文档中的稳定工具名。
- `description` 明确模型何时应调用以及何时不应调用。
- `description` 不写死在 Python 类中，通过 `load_tool_description(name)` 从 YAML 加载。
- `args_schema` 使用 Pydantic 模型，禁止接收无约束 `dict`。
- Repository、RetrievalService 和子图等运行依赖通过构造函数注入，不暴露给模型参数。
- 工具默认在 LangGraph 异步流程中通过 `ainvoke` 执行；异步工具实现 `_arun`。

### 4.2 投标响应检索

```python
class SearchBidResponseTool(BaseTool):
    name: str = "search_bid_response"
    description: str = load_tool_description("search_bid_response")
    args_schema: ClassVar[type[BaseModel]] = SearchBidResponseInput

    model_config = ConfigDict(arbitrary_types_allowed=True)
    task_repository: AuditTaskRepository
    retrieval_service: RetrievalService

    async def _arun(
        self,
        task_id: str,
        bid_file_id: str,
        rule: RuleItem,
    ) -> dict:
        task = self.task_repository.require(task_id)
        require_file_belongs_to_task(bid_file_id, task_id)

        hits = await self.retrieval_service.search(
            query=build_rule_query(rule),
            query_filter=IndexFilter(
                project_id=task.project_id,
                bidder_id=task.bidder_id,
                task_id=task.task_id,
                data_role="bid_document",
                file_ids=[bid_file_id],
            ),
        )
        return build_bid_response_result(rule, hits).model_dump(mode="json")

    def _run(self, **kwargs):
        # 项目内 Agent 图统一异步执行，误用同步入口时明确失败。
        raise ToolException("search_bid_response 仅支持异步调用")
```

### 4.4 证据检索

```python
class SearchEvidenceTool(BaseTool):
    name: str = "search_evidence"
    description: str = load_tool_description("search_evidence")
    args_schema: ClassVar[type[BaseModel]] = SearchEvidenceInput

    retrieval_service: RetrievalService

    async def _arun(self, claim: Claim) -> list[dict]:
        hits = await self.retrieval_service.search(
            query=claim.statement,
            query_filter=IndexFilter(
                project_id=claim.project_id,
                bidder_id=claim.bidder_id,
                task_id=None,
                data_role="evidence_material",
                evidence_types=claim.required_evidence_types,
            ),
        )
        return [
            to_evidence_candidate(hit).model_dump(mode="json")
            for hit in hits
        ]

    def _run(self, **kwargs):
        raise ToolException("search_evidence 仅支持异步调用")
```

### 4.6 确定性比较

```python
def compare_values(operator, expected, actual, value_type, unit=None):
    if actual is None or actual == "":
        return ComparisonResult(status="missing")

    normalized_expected = normalize_value(expected, value_type, unit)
    normalized_actual = normalize_value(actual, value_type, unit)

    match operator:
        case ">=":
            matched = normalized_actual >= normalized_expected
        case "<=":
            matched = normalized_actual <= normalized_expected
        case "equals":
            matched = normalized_actual == normalized_expected
        case "contains_all":
            matched = set(normalized_expected) <= set(normalized_actual)
        case "date_before":
            matched = normalized_actual <= normalized_expected
        case _:
            return ComparisonResult(status="unsupported_operator")

    return ComparisonResult(
        status="matched" if matched else "not_matched",
        raw_expected=expected,
        raw_actual=actual,
        normalized_expected=normalized_expected,
        normalized_actual=normalized_actual,
    )
```

## 5. 工具返回约束

- 工具类统一继承 `langchain_core.tools.BaseTool`。
- Tool 实例由图构建函数创建并注入依赖，不使用全局单例。
- `_run` / `_arun` 返回 `model_dump(mode="json")` 后的 JSON-safe 对象，不返回未序列化的 Pydantic 实例或自由文本大段拼接。
- 候选结果必须包含分数和 SourceRef。
- 工具不能直接修改 AuditState。
- 工具不能改变 RuleSet。
- 工具不能根据文件名直接下证据结论。
- 所有身份参数在服务端二次校验。

主 Agent 传给 `request_evidence_review` 的 Claim 属于受信任的内部契约，子 Agent 不重复执行业务身份核验；资料检索仍按 Claim 中的 project_id、bidder_id 和证据类型执行强制过滤。

## 6. 错误处理

```python
try:
    result = await search(...)
    return result.model_dump(mode="json")
except TimeoutError:
    return ToolFailure(
        error=TaskError(
            code="tool_timeout",
            stage="bid_search",
            retryable=True,
            ...
        )
    ).model_dump(mode="json")
except IdentityViolation as exc:
    # 身份越界不是可降级的“无结果”，明确中止本次工具调用。
    raise ToolException(str(exc)) from exc
```

工具失败应可被 Agent 转换为 `manual_review`，只有上下文损坏等不可恢复错误才终止任务。

## 7. 测试设计

- 每个 Tool 的 `args_schema` 能拒绝缺失字段和额外非法字段。
- Tool 的 `name` 与设计文档约定完全一致。
- Tool description 与 YAML 配置一致，YAML 缺项时测试失败。
- 传入其他 task 的 file_id 必须被拒绝。
- 传入其他 bidder 的 candidate 必须被拒绝。
- `search_evidence` 强制使用 Claim 的证据类型。
- 数值、日期、空字段、枚举、列表、型号和包号比较有独立测试。
- 单位转换无法确认时返回 `manual/unsupported`，不猜测。
- 原文回查返回解析状态和精确来源。

## 8. 验收标准

- 五个 `BaseTool` 类具有明确的 `name`、`description`、`args_schema` 和返回模型。
- 工具通过实例注入到主/子 Agent，项目中不使用 `@tool` 装饰器。
- 确定性比较不注册为 LLM Tool。
- 工具结果足以支持主/子 Agent 判断和报告溯源。
- 数据隔离测试全部通过。
