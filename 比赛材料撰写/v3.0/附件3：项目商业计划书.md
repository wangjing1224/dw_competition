## 一、项目方案概述（不超过200字）

标智通面向招投标审核中要求分散、证明材料繁多、跨文件核对工作量大的问题，提供集规则整理、资料管理、协同核验和报告交付于一体的智能审核工作台。通过领域专用多智能体执行机制，辅助采购人员梳理条件、查证材料、识别疑点并逐项复核。项目拟形成线上订阅与自行部署年度授权两种服务：线上提供模型选择和持续使用，自行部署支持机构管理运行环境，共同服务内部预审与会审准备，减少重复整理和成果交接负担。

## 三、项目产品（服务）化（不超过2000字）

### 1.项目产品（服务）特性

标智通提供面向多附件招投标材料的智能审核工作台，服务机构内部预审与会审准备。用户导入招标要求、投标响应及授权支撑资料，确认审核范围后，由系统组织条件整理、资料查证和意见生成，再由业务人员复核关键结论。产品将文件处理、智能核验和成果交付放入连续工作流程，帮助采购团队把精力集中于疑点判断与业务处置。

**智能协同，承担重复的信息处理。** 系统读取Word、Excel、PDF及图片，整理项目要求与企业资料，围绕响应内容调用检索、图片查阅和计算工具开展核验，并逐项生成发现、理由和待核事项。领域专用执行框架与四类智能体连接准备和审核环节，减少人工逐份整理、反复检索及汇总意见的操作需求。智能化覆盖工作过程，人员仍承担范围确认、规则校核和结论复核。

**业务界面，便于任务组织与使用。** 浏览器工作台按规则库、资料库、审核任务和报告组织操作，承接材料导入、双库选择、过程查看和结果复核。业务人员围绕具体采购项目工作，系统在后台组织智能体及工具调用；审核进度和成果集中展示，便于发现待处理事项。产品化将进一步统一操作引导、错误提示和培训材料，使团队成员能够按同一流程开展工作。

**材料复用，支持连续项目积累。** 项目规则与企业资料独立维护，审核任务选择适用双库并保存当次快照。企业证明材料形成摘要、事实记录和原文入口，后续任务可在确认授权、时效及适用范围后复用。新项目使用自身招标条件，已有资料则按当前对象、版本和证明范围重新判断，避免将往次结论直接套用；复用价值来自减少重复准备和维护已有业务成果。

**成果可复核，便于会审与交接。** 报告集中呈现逐项发现、判断理由及待核事项，已登记并填入报告的来源展示引用摘录，支持打开来源材料回看，执行记录用于过程回查。业务人员可以结合原件检查事实与结论，利用网页、Word等成果开展会审、反馈和归档。对证明不足或关系未明的事项保留待核原因，使后续补充资料与人工确认有明确对象。

现有原型已完成两类材料验证，形成从材料接入到报告交付的产品基础。

| 验证场景 | 已有结果与范围 |
| --- | --- |
| 红外成像仪招投标脱敏测试 | 40份输入文件；120个要求主题检出率99.17%，334个源条件完整保留率70.96% |
| 地方文献数字化加工服务招投标模拟测试 | 25份混合格式文件；102个固定判定项的三态标签正确率95.10%，22项预设不符合事项召回率95.45% |
| 流程交付 | 两类测试合计43份支撑资料完成入库，5份适用待审文件形成内容报告 |

主题检出包含部分识别；模拟测试采用受控样本。评价口径与典型案例见项目说明书。

### 2.产品（服务）化实施计划

**第一阶段：统一产品核心与交付文档。** 以现有原型为基础，统一审核核心、软件版本和模型适配清单，形成安装说明、操作手册、版本更新及故障处理文档。完善基础认证、授权与备份恢复能力，为线上服务和客户自行部署提供共同的软件基础。

**第二阶段：建设线上订阅与数据保护能力。** 补齐账号认证、机构数据隔离、订阅计费和用量管理，提供已适配模型选择及任务级配置记录。线上服务由团队统一维护，通过加密传输、访问控制、受限日志和备份恢复保护资料，提供保存期限设置与删除入口；明确模型调用的数据路径，平台不将客户材料用于训练，并选用符合相应数据使用约定的模型服务。完成权限、运行和数据处理验证后开放付费服务。

**第三阶段：形成两种持续使用方案。** 线上版面向希望直接使用的采购人员和机构团队，提供基础、专业档位及月付、年付选择；自行部署版面向具备IT条件的机构，提供年度软件授权、更新支持及硬件选型建议，设备、模型服务和实际部署运维由客户负责。围绕授权材料开展完整流程使用评估，完善操作引导与支持清单。

**第四阶段：建立订阅运营与版本维护机制。** 持续发布缺陷修复、模型兼容更新和操作说明，线上版本由团队维护，自行部署版本由客户安排安装更新。跟踪活跃使用、续费、模型消耗及支持需求，将共性问题转化为标准功能和知识文档，随着付费用户增长扩充服务资源。

## 四、项目产品（服务）市场与竞争（不超过2000字）

### 1.市场概述

招投标智能审核面向政府与企业采购中的材料审查需求，应用涉及货物、工程和专业服务等领域。财政部数据显示，2025年全国政府采购规模为33212.96亿元，其中公开招标占采购金额的77.49%。[财政部统计](https://gks.mof.gov.cn/tongjishuju/202609/t20260928_3998199.htm) 广泛开展的采购活动持续产生招标文件、投标响应及资质业绩等材料，为审核软件与服务提供业务基础。

从业务分工看，采购单位需要核对响应是否满足项目要求、证明材料是否充分；招标代理机构需要组织多个项目的材料审查和成果交接；投标企业需要在提交前发现遗漏、矛盾及响应偏差。这些任务共同涉及信息查找、条件比对和依据整理，且受到项目时间安排约束。减少重复处理、降低疏漏风险、便于结果复核，是不同用户采用智能审核工具的主要价值诉求。

政策推动与公开采购需求进一步明确了市场发展方向。2026年国家发展改革委等部门出台实施意见，推动投标合规自查、智能辅助评标等应用，并提出培育人工智能应用服务商。[政策依据](https://www.ndrc.gov.cn/xwdt/tzgg/202602/t20260210_1403681_ext.html) 三峡集团同年采购招投标人工智能应用建设服务，内容包含辅助评标、部署迭代及既有平台集成。[采购需求依据](https://eps.ctg.com.cn/cms/channel/2ywgg1/240637086.htm) 这些政策和采购动向表明，行业需求已延伸至材料内容理解与辅助判断，相关软件、系统适配和持续服务具有明确的应用方向。

### 2.竞争优势分析

标智通围绕复杂材料审核、业务操作与成果交付、跨项目适配与复用，形成三方面竞争优势。

**领域化审核组织，复杂材料处理有实测优势。** 系统针对要求分散、限定条件易遗漏和证明关系复杂等问题，组织条件提取、规则归并与关联核验。在红外成像仪招投标脱敏测试中，与接入同型号百炼DeepSeek V4.1 Flash的Claude Code完整流程相比，本系统要求主题检出率为99.17%，参照为77.50%；334个源条件完整保留率为70.96%，参照为23.65%；专项审核单元覆盖率为87.78%，参照为31.11%。这些结果体现了系统在要求整理、细项保留和重点事项审核上的优势，为后续逐项判断与人工复核提供更充分的材料基础。

**专业流程封装，降低操作门槛并贯通成果交付。** 系统内置领域提示词、材料读取与核验流程，用户通过页面选择文件、绑定规则库与资料库，即可发起审核。相较于自行使用通用智能体搭建审核方案，业务人员无需逐次设计长提示词、编排工具调用或管理长任务上下文。流程自动形成逐项发现、判断理由和待核事项，支持网页浏览、一键下载Word及导出Markdown、JSON；报告展示已登记的来源摘录与章节、页码等信息，可打开来源材料搜索正文、查看图片和下载原件。审核、依据回看与报告交付在同一工作台完成，减少整理对话、复制证据和编排报告格式的操作，便于团队统一使用及成果交接。

**项目规则自适应与资料复用，拓展应用场景。** 行业差异由当次招标要求和证明材料承载，规则库与资料库独立维护，使不同采购项目复用同一审核内核。已建库的企业资料可在确认时效与适用范围后用于后续任务，任务保存当次版本，支持业务资料持续积累。现有验证覆盖红外成像仪设备采购与地方文献数字化加工服务采购；后者模拟测试的三态标签正确率为95.10%，不符合事项召回率为95.45%。基于两类采购的应用基础，产品可面向采购方响应核对、代理机构材料预审和投标方自查拓展，将共性审核能力用于不同主体与采购任务。

### 3.项目实施风险及应对措施

| 风险情境与影响 | 应对措施 |
| --- | --- |
| 扫描不清、版本冲突或证明范围不明，可能导致误判及额外复核，影响验收与续用 | 确认材料范围，保留理由、来源线索及待核事项；通过约定样本验收，按错误类型改进 |
| 模型或通用智能体进步，可能缩小现有处理优势 | 保留模型替换空间，持续比较实际任务效果，围绕业务流程、成果交付和客户支持维护产品价值 |
| 线上数据访问越权、保存不当或外部模型调用范围不清 | 建设身份认证、数据隔离、访问记录及删除机制，明确模型数据流向；自行部署提供兼容与配置说明 |
| 高价模型或大规模材料推高调用和服务成本 | 按模型计量并展示套餐额度，提供用量提示与补充选项，结合任务排队和存储管理控制成本 |
| 需求分散、续费或回款不及计划，挤占研发及周转资金 | 维护统一版本，按订单开通授权；研发与销售投入匹配已确认业务，保留周转余量 |

首期重点控制审核质量与客户数据保护。使用评估同时查看任务完成、关键错误和人工复核负担，结合业务人员反馈改进模型输出与依据交付。线上版在开放付费前完成访问隔离和数据处理验证，明确保存期限及删除流程；自行部署版说明所选模型的数据流向，协助客户判断运行条件与材料使用要求是否匹配。

经营上优先维护统一核心版本，新增需求先评估共性价值与工作量，再安排产品迭代。按客户跟踪实际支持成本、回款和后续服务义务；销售或支持投入偏离计划时，控制扩招和非必要功能开发，保留周转余量。需求与政策提供进入机会，持续经营仍依赖可用成果、客户续用及可控制的服务成本。

## 五、商业模式（不超过2000字）

### 1.项目产品（服务）的开发、生产（服务）策略

采用“共用审核核心、线上订阅与自行部署并行”的产品策略。线上版由团队提供应用运行环境、模型调用、平台维护和数据保护服务，用户通过浏览器选择已适配模型开展审核；按月或按年持续使用，满足个人经办及机构团队的日常需求。

自行部署版按年度提供软件授权、版本更新、使用技术支持与硬件选型建议。客户自行或委托IT服务商安装应用、配置设备与模型并运维，承担相应资源费用；团队维护软件、提供安装文档和使用支持，不承担具体部署工程。年度授权期间不按项目数量或审核轮次收费。

两种版本复用同一业务内核和迭代成果。线上侧重点建设便捷使用、模型选择与订阅运营，自行部署侧提供稳定版本及机构适配说明。持续优化材料复用、上下文组织和工具调用，减少重复输入与无效往返；结合厂商API适配、缓存利用和模型选型，降低单位审核成本。

### 2.项目产品（服务）的营销策略

**定向获客，以业务案例吸引目标用户。** 首期重点触达经常参与投标的企业经办人员和中小招标代理团队，围绕“提交前自查”“会审前预审”，用现有脱敏与模拟材料制作操作短片、案例和审核清单，通过招采业务社群、专业培训交流及线上专题演示获客，定向邀请有重复审核需求的团队体验。拟与采购培训机构、行业软件服务商开展推荐合作，按实际付费转化结算渠道费用；对具备IT条件的机构推介自行部署年度授权。后三季度分别以新增60、60和80个付费账户为目标，记录各渠道咨询、体验及付费结果，集中投入转化较好的渠道。

**体验转化，以首次成果带动续用。** 提供限时、限额度体验，配套样例材料、操作引导和集中答疑，帮助用户完成首次材料导入、审核与来源回看，以可复核报告建立使用信任。为阶段性需求提供月付入口，对连续审核需求以年付优惠引导长期订阅，年价相当于10个月月费。持续提供资料复用指引和版本更新说明，到期前回访使用问题、跟进处理并提示续费，以老用户推荐拓展同类客户；采用标准教程与共性问题答疑，减少逐户培训负担。

| 线上专业版 | 799元／月 | 7990元／年 | 更多已适配模型、更高计算额度与存储空间、优先任务队列和使用支持 |

线上用户无需配置模型账号，不按项目数量或审核轮次收费。月付按月购买，年付一次支付12个月费用、计算资源按月提供。套餐拟按模型方案计量文本输入输出、图像解析等资源消耗，展示任务用量与余额，支持补充或升级。上线前将结合材料规模、扫描件比例、模型配置及完整审核流程核验资源消耗，确定并公示计算额度、存储和并发边界。核验覆盖规则与资料入库、关联查证和报告生成，区分首次处理与资料复用。自行部署版由客户提供模型和设备，按年获得软件授权及配套服务。

持续付费由连续审核需求和可复用的业务成果支撑。对经常开展采购、代理或投标业务的客户，新项目持续带来规则整理与材料核验需求；已有企业证明资料可在确认时效和适用范围后用于后续任务，统一工作台和报告形式减少重复准备、流程组织与成果交接。线上订阅持续提供计算资源、平台维护和模型适配，自行部署年度服务提供软件更新和使用支持，使客户在后续项目中继续获得审核能力与服务保障。

成本主要包括模型调用、托管、支付渠道及人员等支出。通过套餐用量管理控制线上资源消耗，以统一软件版本、标准教程和共性问题支持减少逐户交付投入；自行部署客户承担设备与模型费用，团队承担软件维护和使用支持。两种路线共用审核内核，使研发成果服务更多客户、摊薄共性投入，订阅及授权收入在覆盖服务和运营成本后形成经营收益。

### 4.（若创业）企业发展计划

第一季度开展产品化，第二季度完成线上服务必需能力、启动付费并完善自行部署交付包。首年目标累计获得200个线上付费账户，基础与专业各占一半。前两年拟配置2名核心人员，统一承担研发、运维和客户支持，第三年随业务扩大增至3名；以共用软件版本支持两种交付方式，依据活跃量和服务负载增加资源。

拟分阶段筹措20万元启动资金，用于上线前的人员、产品化工具和推广投入，并预留模型与运营周转资金。年度预收款按后续服务需要保留资源，依据成交、续费与服务成本安排扩张。
