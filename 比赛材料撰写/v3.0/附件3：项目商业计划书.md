## 三、项目产品（服务）化（不超过2000字）

### 1.项目产品（服务）特性

标智通面向多附件招投标材料，提供项目要求整理、响应性审核与证明材料一致性核验。现有原型以领域专用多智能体执行框架贯通规则建库、资料建库、核验执行和报告交付，统一组织信息进入、资料范围及逐项业务状态；机构版年度服务、嵌入式模块及接口适配为后续产品化规划。同一审核内核已完成设备采购脱敏材料测试与专业服务采购受控模拟测试，验证承接不同项目规则和资料结构的基础。

**先保留文件条件，再整合项目规则。** 招标要求常分散在正文、技术附件和补充说明中，同一主题还可能包含不同对象、时间和例外。系统先提取当前文件的候选要求，再结合已有规则进行归并，分别组织条件收集与规则整合，形成可供业务人员校核的项目规则库。新项目通过自身材料生成审核依据，复用已有审核流程。

**围绕共同事实组织核验，分别形成合规判断。** 主审核智能体将涉及同一对象或事实的多条规则关联到具体核验事项，写明判断条件与证据缺口；资料核验智能体在选定文件及直接关联资料范围内查证，返回事实、证明范围和未确认项，主审再依据各条规则判断。例如，一份交付记录的版本、数量和时间可以服务于不同要求的核验，避免把“存在证明材料”等同于“满足全部要求”。

**保存审核成果，支持逐项复核和业务交接。** 阅读进度、核验记录与报告草稿持续保存，审核意见随查证结果逐步补充和修订。报告呈现实际发现、判断理由及待核事项，已登记并填入报告的来源支持原文定位，执行记录提供过程回查；发布前检查报告结构、规则覆盖和已填来源的合法性。业务人员据此检查条件是否完整、事实是否属于当前对象与版本、证据是否支持意见，再确认结论或补充材料，形成可交接的审核成果。

产品已经历两类材料验证。红外成像仪招投标脱敏测试包含12份规则源文件、25份投标方资料及3份测试文件，反映真实材料中要求分散和证明链较长的特点；地方文献数字化加工服务招投标模拟测试包含25份混合格式文件、3家模拟投标方，设置102个标注判定单元，覆盖版本、数量、时效、人员与交付证明的关联核验。

| 验证层次 | 已有实测结果与范围 |
| --- | --- |
| 规则与资料组织 | 红外成像仪脱敏测试中，120个主题的检出率99.17%，334个源条件的完整保留率70.96%，33项重点资料事实完整可恢复率100% |
| 跨场景辅助判断 | 地方文献数字化加工服务模拟测试中，34个主题及89个源条件完整保留；102个判定项的三态标签正确率95.10%，22项预设不符合事项召回率95.45%；系统判为不符合的21项均与标准答案一致，精确率100.00% |
| 流程交付 | 两类测试合计43份资料已完成入库，5份适用待审文件均形成内容报告 |

上述指标按各自对象评价：主题检出包含部分覆盖，重点事实为既有检查点的事后专项复核，模拟材料用于开发回归；规则覆盖、判定正确性和交付完成分别评价。现有结果用于说明产品基础和适用范围，客户节时与降本须依据实际使用记录核算。

### 2.产品（服务）化实施计划

产品化以现有原型和测试成果为起点，先形成标准工作台，再提供机构服务与模块接入。首期围绕安装、导入、规则确认、核验、人工复核及报告导出整理部署包、操作手册、培训材料和服务清单。机构服务约定席位、文件规模、模型用量及服务响应；模块接入围绕客户已有任务和资料流程返回审核结果。

首期拟面向承担城市设备更新和公共服务采购的机构采购团队，以内部材料预审与会审准备为切入点。经办人员导入当次招标要求、已接收响应及经授权可用的证明材料，确认规则与材料范围，系统形成逐项发现、理由和待核事项，业务人员据此开展会审与问题反馈。资料是否属于当前提交范围由业务人员确认，尚未确认范围的缺口列为待核事项。首期交付聚焦材料准备、条件确认、辅助核验和报告交接，该路径为后续应用规划，不计入已部署客户。

统一维护文档处理、规则构建、证据核验和报告核心，客户差异通过项目规则、配置及约定接口表达。标准交付明确环境配置、初始资料组织、培训与验收范围，专项适配另行报价。机构部署按客户要求配置认证授权、访问审计、数据保留和模型调用边界，硬件及专属模型资源单列。后续质量迭代与日常维护按真实使用反馈安排。

## 四、项目产品（服务）市场与竞争（不超过2000字）

### 1.市场概述

政府与企业采购持续产生招标文件、技术附件、资格资料、履约证明及投标响应，业务人员需要核对大量分散信息。财政部公布，2025年全国政府采购规模为33212.96亿元，公开招标占77.49%。采购活动构成材料审核工具的应用基础，软件服务收入则取决于客户数量、审核需求与实际付费水平。[财政部统计](https://gks.mof.gov.cn/tongjishuju/202609/t20260928_3998199.htm)

2026年相关实施意见提出投标合规自查、智能辅助评标等应用，推动人工智能与既有招投标业务系统融合。标智通选择材料辅助审核切入，围绕文件理解、证据核验和报告交付提供能力，保留业务人员确认结论的环节。[政策依据](https://www.ndrc.gov.cn/xwdt/tzgg/202602/t20260210_1403681_ext.html)

首期拟优先服务承担城市设备更新和公共服务采购、具有重复材料审核需求的机构采购团队，以内部预审与会审准备为使用环节。项目经办人员直接使用，采购负责人及信息化部门评估费用、部署和材料使用范围；后续向代理机构及采购平台服务商拓展。上述为市场进入规划，当前不计入已触达客户或实际订单。

市场拓展以能够触达并满足服务条件的机构为基础，不按采购交易总额估算软件销售。首期商业化预测按6家机构客户规划，聚焦有限客户的有效使用和服务质量；后续依续费、新增合同及交付能力扩大规模。当前已具备原型和测试依据，尚未形成付费客户业绩，预测客户数属于经营目标。

### 2.竞争优势分析

现有招采数字化供给包括专业平台的辅助审核服务、专项审查工具，以及通用智能体驱动的文档处理方案。专业产品承接材料理解与辅助审核需求，通用智能体提供灵活的工具调用与处理路径。本项目聚焦复杂多附件任务，围绕条件组织、跨文件事实核验和逐项成果交付形成具体设计，按可验证的处理结果说明其价值。

标智通选择多附件复杂材料作为切入点，在领域专用多智能体执行框架中实现三项具体机制：将当前文件条件提取与历史规则归并分开，使当前文件的条件收集不受既有规则内容直接影响；按共同事实关联多条规则，分别组织查证与判断；将规则、核验记录和报告草稿持续保存，使审核成果能够逐项复核和交接。这些设计已经在现有原型中运行，具体效果以当前样本的分项指标说明。

主要实测参照采用Claude Code 2.1.296接入同型号百炼DeepSeek V4.1 Flash，比较领域专用执行框架与通用智能体的完整处理流程。在红外成像仪脱敏材料的334个源条件中，本系统完整保留率为70.96%，参照为23.65%；本轮优势集中在复杂要求保留、资料整理和专项审核覆盖。解析、提示词和预算差异属于本轮完整方案比较的条件，结果不用于分配单机制因果增益。更多指标及评价范围见项目说明书和[佐证1：红外成像仪对照报告](../tmp/测试报告/2026-10-12_ClaudeCode_DeepSeek_红外成像仪脱敏测试_量化对照报告.md)。

当前竞争基础是已经实现的多附件审核流程、可维护的项目规则和可复核交付。机构使用者可取得项目要求清单、按事项组织的审核意见及资料线索，用于会审准备和问题核对。模型升级可以进入现有流程，领域组织方式的持续价值仍由具体任务效果衡量；后续随真实使用积累解析适配、规则处理经验和交付规范。

公开价格提供了初期定价参照。臻善智标官网列示9800元及19800元年度套餐，说明招投标智能工具已存在年度订阅收费形式。不同套餐的功能、用量、服务及税费口径存在差异，公开价格仅供价位参考。标智通结合机构协作、复杂材料核验及交付支持设计自身报价。[臻善智标官网](https://zszbai.com)

## 五、商业模式（不超过2000字）

### 1.项目产品（服务）的开发、生产（服务）策略

采用“统一软件核心、机构年度服务、专项适配交付”的经营方式。团队持续维护解析、规则、证据核验与报告能力；客户按服务档位使用产品，需要对接内部系统时实施专项适配。标准工作台采用团队管理的服务环境，嵌入模块按约定实例部署。私有算力、超出标准范围的接口和专业数据服务另行核价。

研发围绕审核质量、材料处理及使用流程持续迭代。交付依次完成范围确认、环境与资料配置、使用培训、联合验收和维护，形成标准文档及配置清单。研发、实施与客户支持均计入劳动报酬，采用核心成员与项目制协作相结合的方式控制早期固定支出。

### 2.项目产品（服务）的营销策略

拟结合已有运行报告制作演示录屏，展示多文件要求组织、具体疑点核验及人工复核入口。优先接触有重复审核需求的机构采购团队，通过需求访谈确认文件规模、材料可用范围、复核责任和部署要求，再按约定范围提供使用评估。

客户购买的是审核工作台、可校核的项目规则、逐项审核报告及相应资料线索，用于内部会审和问题核对，团队提供安装、培训与日常支持。转为年度服务的条件包括需求与服务范围匹配、客户认可交付内容及双方确认收费额度；节时收益按真实使用记录测算。首年6家客户仍为经营目标。后续面向代理机构及平台服务商开展渠道合作，新增客户、续费及回款分别跟踪。

### 4.（若创业）企业发展计划

商业化初期明确成果权属、开源依赖和团队职责，围绕标准工作台建立服务能力。拟筹措45万元启动资金，其中40万元用于研发交付周转，5万元作为现金安全储备；资金来源拟由团队自筹与创业孵化、社会投入组合解决，尚未计入已落实融资。随着续费和交付规模增加，逐步扩充研发及客户支持，固定投入与实际合同同步。

假设年度服务预付、首次实施验收收款，并将签约简化为年中生效，三年合同及收款预算分别为36.0、72.0、112.8万元；营业收入按服务期确认。按费用均匀支出、实施费用在收款前发生估算，三年周转峰值缺口约35.2万元，启动资金另留缓冲。实际经营逐月跟踪应收款与服务义务，销售放缓时先控制扩招和非必要投入。

## 六、预期经济效益分析（不超过500字）

基准预测按机构版年费4.8万元、首次实施1.2万元测算。合同按年中生效，年费跨年度确认；完整服务当量为当年与上年签约合同数之和的一半。营业收入=服务当量×4.8+新增客户×1.2；直接成本=服务当量×1.2+新增客户×0.6。期间费用含研发、销售及管理。
